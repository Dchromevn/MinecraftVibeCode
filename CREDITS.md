# CREDITS.md — Ghi công tài nguyên

## Texture và icon

- **REFI_Textures** — tác giả MysticTempest.
  Nguồn: https://github.com/MysticTempest/REFI_Textures
  Giấy phép: CC BY-SA 4.0 (https://creativecommons.org/licenses/by-sa/4.0/).
  Dùng cho texture block, icon vật phẩm, khung hotbar, vết nứt và skin nhân vật
  trong `/client/public/textures`, `/client/public/icons`, `/client/public/ui`.
  Các file được sao chép, đổi tên, ghép hoặc cắt từ gói gốc bằng
  `npm run import-textures`; bảng ánh xạ ở `scripts/texture-map.json`.

## Thư viện mã nguồn

- Three.js (MIT), Vite (MIT), ws (MIT), TypeScript (Apache-2.0),
  tsx (MIT), concurrently (MIT), pngjs (MIT, chỉ dùng trong script nhập texture).

## Ghi chú

Mọi texture, model, âm thanh, tên và logo đều là nguyên bản hoặc có giấy phép
mở. Dự án không dùng tài nguyên của Minecraft/Mojang.
