# ITEMS.md — Danh sách vật phẩm

Tạo tự động bằng `npm run list-items` (đừng sửa tay). Dùng khóa ở cột đầu cho lệnh quản trị:

```
/give <tên người chơi> <khóa> [số lượng]
```

Ví dụ: `/give An diamond_sword`, `/give An tnt 16`. Trong game gõ `/items <từ khóa>` để tìm (tìm được theo tên tiếng Việt, không cần dấu: `/items thit`).
